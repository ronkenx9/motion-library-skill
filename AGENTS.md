# Agent notes

This repository is an Agent Skill named `motion-library`. It follows the open Agent Skills format (a folder with `SKILL.md`, plus optional `references/` and `scripts/`).

If your tool loads skills automatically, install the `motion-library/` folder into your skills directory. See the README for Claude Code (`~/.claude/skills` or `.claude/skills`) and Codex (`~/.agents/skills` or `.agents/skills`, with `~/.codex/skills` as a fallback on older builds).

If it does not, read `motion-library/SKILL.md` first whenever the user asks to break down a motion-design video, grow a motion technique library, or storyboard an original motion piece from references. Then follow that skill, and load files under `motion-library/references/` as needed.

Do not copy the reference videos. Learn why they work, then invent. Never post or publish the work; hand it to the owner.

The repo also holds a second skill, `launch-storyboard/`. For a product launch film, read `launch-storyboard/SKILL.md` first to build the board (brief, hook, arc, real UI library found online, 4–6 frames), then use `motion-library` on it.
